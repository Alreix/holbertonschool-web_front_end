# holbertonschool-web_front_end

This repository contains projects completed as part of the Holberton School Web Front-End curriculum.

The goal of this repository is to practice the foundations of front-end development through HTML, CSS, and JavaScript-related exercises.

Each project focuses on a specific front-end concept and helps build a better understanding of how web pages are structured, styled, and prepared for user interaction.

## Projects

### html_advanced

This project focuses on advanced HTML structure.

It contains exercises about:
- creating the structure of a web page;
- using semantic HTML tags;
- organizing page sections;
- adding headings, paragraphs, links, images, and lists;
- building the skeleton of a complete website without CSS styling.

### CSS_advanced

This project focuses on advanced CSS styling.

It contains exercises about:
- applying styles to an HTML page;
- using selectors;
- working with colors, fonts, spacing, and layout;
- styling headers, sections, buttons, and cards;
- improving the visual design of a web page;
- connecting HTML structure with CSS rules.
